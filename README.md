# MasterTao

A responsive and interactive website built with **HTML, CSS, JavaScript, and Bootstrap**.

## 📖 About the Project

**MasterTao** is a frontend project developed to practice creating a responsive and interactive web interface based on a provided design.

The project combines semantic HTML, responsive CSS, Bootstrap components and JavaScript functionality to provide a consistent user experience across different screen sizes.

## ✨ Features

* 📱 Responsive design
* 💻 Desktop and mobile layouts
* 🎨 Modern and clean UI
* 🧩 Semantic HTML structure
* ⚡ JavaScript interactions
* 🧱 Bootstrap components and utilities
* 📐 Responsive layout with CSS and Bootstrap
* 🖼️ Static assets and images
* 🌐 GitHub Pages deployment

## 🚀 Getting Started

### Clone the repository

```bash id="9qv8f0"
git clone https://github.com/KatarginaKate/build_MasterTao.git
```

### Navigate to the project

```bash id="x6y7j1"
cd build_MasterTao
```

### Run the project

This is a static frontend project, so no additional installation or build process is required.

Open `index.html` in your browser or use the **Live Server** extension in VS Code.
